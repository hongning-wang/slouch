# Slouch

A tiny local browser app. Sit upright to calibrate; sustained slouching repeatedly plays your chosen audio or video until you sit straight. Camera preview, status, Start/Stop, Recalibrate. No account or remote processing.

Requires Node.js 20+ and a modern Chrome or Edge browser with a webcam.

```sh
npm install
npm run setup
npm start -- --video "/path/to/audio.mp4"
```

Built entirely with Codex.
